### Window mockup
Window mockup shows a box that looks like an operating system window.

[Window mockup documentation](https://v4.daisyui.com/components/mockup-window/)

#### Class names
- component: `mockup-window`

#### Syntax
```html
<div class="mockup-window">
  <div>Content</div>
</div>
```
#### Rules
- Wrap content inside `mockup-window`.
