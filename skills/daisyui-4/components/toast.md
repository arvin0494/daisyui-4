### Toast
Toast is a wrapper that stacks elements, positioned on the corner of the page.

[Toast documentation](https://v4.daisyui.com/components/toast/)

#### Class names
- component: `toast`
- modifier: `toast-start`, `toast-center`, `toast-end`, `toast-top`, `toast-middle`, `toast-bottom`

#### Syntax
```html
<div class="toast">
  <div>Message</div>
</div>
```
#### Rules
- `toast` is a positioned container; `toast-start` / `toast-center` / `toast-end` / `toast-top` / `toast-middle` / `toast-bottom` position it.
- Put an `alert` inside a `toast` for a styled message.
