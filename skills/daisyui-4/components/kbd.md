### Kbd
Kbd is used to display keyboard shortcuts.

[Kbd documentation](https://v4.daisyui.com/components/kbd/)

#### Class names
- component: `kbd`
- size: `kbd-lg`, `kbd-md`, `kbd-sm`, `kbd-xs`

#### Syntax
```html
<kbd class="kbd">K</kbd>
```
#### Rules
- Sizes: `kbd-lg`, `kbd-md`, `kbd-sm`, `kbd-xs`.
