### Radio
Radio buttons allow the user to select one option from a set.

[Radio documentation](https://v4.daisyui.com/components/radio/)

#### Class names
- component: `form-control`, `label`, `radio`
- color: `radio-primary`, `radio-secondary`, `radio-accent`, `radio-success`, `radio-warning`, `radio-info`, `radio-error`
- size: `radio-lg`, `radio-md`, `radio-sm`, `radio-xs`

#### Syntax
```html
<input type="radio" class="radio" />
```
#### Rules
- Add one color (`radio-primary`) and one size (`radio-lg`).
- Wrap with a `label` and `form-control` for labels and spacing.
