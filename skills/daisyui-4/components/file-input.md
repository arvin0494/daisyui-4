### File Input
File Input is an input field for uploading files.

[File Input documentation](https://v4.daisyui.com/components/file-input/)

#### Class names
- component: `form-control`, `label`, `file-input`
- color: `file-input-ghost`, `file-input-primary`, `file-input-secondary`, `file-input-accent`, `file-input-info`, `file-input-success`, `file-input-warning`, `file-input-error`
- size: `file-input-lg`, `file-input-md`, `file-input-sm`, `file-input-xs`
- modifier: `file-input-bordered`

#### Syntax
```html
<input type="file" class="file-input" />
```
#### Rules
- Wrap in `form-control` and `label` for spacing and a label.
- Add one color (`file-input-primary`) or a style (`file-input-bordered`, `file-input-ghost`), and one size.
