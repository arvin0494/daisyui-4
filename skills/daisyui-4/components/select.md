### Select
Select is used to pick a value from a list of options.

[Select documentation](https://v4.daisyui.com/components/select/)

#### Class names
- component: `form-control`, `label`, `select`
- color: `select-ghost`, `select-primary`, `select-secondary`, `select-accent`, `select-info`, `select-success`, `select-warning`, `select-error`
- size: `select-lg`, `select-md`, `select-sm`, `select-xs`
- modifier: `select-bordered`

#### Syntax
```html
<select class="select">
  <option>A</option><option>B</option>
</select>
```
#### Rules
- Wrap in `form-control` and `label` for spacing and a label.
- Add one color (`select-primary`) or a style (`select-bordered`, `select-ghost`), one size, and `select-error` for an error state.
