### Code mockup
Code mockup is used to show a block of code in a box that looks like a code editor.

[Code mockup documentation](https://v4.daisyui.com/components/mockup-code/)

#### Class names
- component: `mockup-code`

#### Syntax
```html
<div class="mockup-code">
  <pre><code>&lt;div&gt;&lt;/div&gt;</code></pre>
</div>
```
#### Rules
- Wrap code in `<pre><code>` inside `mockup-code`.
