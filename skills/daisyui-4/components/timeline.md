### Timeline
Timeline component shows a list of events in chronological order.

[Timeline documentation](https://v4.daisyui.com/components/timeline/)

#### Class names
- component: `timeline`, `timeline-start`, `timeline-middle`, `timeline-end`
- modifier: `timeline-compact`, `timeline-snap-icon`, `timeline-vertical`, `timeline-horizontal`, `timeline-box`

#### Syntax
```html
<ul class="timeline">
  <li><li class="timeline-start">Text</li></li>
</ul>
```
#### Rules
- `timeline-start` / `timeline-middle` / `timeline-end` place content relative to the timeline dots.
- Use `timeline-vertical` / `timeline-horizontal` and `timeline-compact` for layout.
