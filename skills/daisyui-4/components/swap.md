### Swap
Swap allows you to toggle the visibility of two elements using a checkbox or a class name.

[Swap documentation](https://v4.daisyui.com/components/swap/)

#### Class names
- component: `swap`, `swap-on`, `swap-off`, `swap-indeterminate`
- behavior: `swap-active`, `swap-rotate`, `swap-flip`

#### Syntax
```html
<div class="swap">
  <div class="swap-off">Off</div>
  <div class="swap-on">On</div>
</div>
```
#### Rules
- `swap-off` / `swap-on` are the two toggled elements.
- Add `swap-active` (controlled by state), `swap-rotate`, or `swap-flip` for the transition.
