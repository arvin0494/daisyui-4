### Text Input
Text Input is a simple input field.

[Text Input documentation](https://v4.daisyui.com/components/input/)

#### Class names
- component: `form-control`, `label`, `input`
- color: `input-ghost`, `input-primary`, `input-secondary`, `input-accent`, `input-info`, `input-success`, `input-warning`, `input-error`
- size: `input-lg`, `input-md`, `input-sm`, `input-xs`
- modifier: `input-bordered`

#### Syntax
```html
<input type="text" class="input" placeholder="Email" />
```
#### Rules
- Wrap in `form-control` and `label` for spacing and a label.
- Add one color (`input-primary`) or a style (`input-bordered`, `input-ghost`), one size, and `input-error` for an error state.
