### Radial progress
Radial progress can be used to show the progress of a task or to show the passing of time.

[Radial progress documentation](https://v4.daisyui.com/components/radial-progress/)

#### Class names
- component: `radial-progress`

#### Syntax
```html
<div class="radial-progress" style="--value:70;--thickness:12px;">70%</div>
```
#### Rules
- Set `--value` and `--digits` inline styles, and `--thickness` for the ring width.
