### Progress
Progress bar can be used to show the progress of a task or to show the passing of time.

[Progress documentation](https://v4.daisyui.com/components/progress/)

#### Class names
- component: `progress`
- color: `progress-primary`, `progress-secondary`, `progress-accent`, `progress-info`, `progress-success`, `progress-warning`, `progress-error`

#### Syntax
```html
<progress class="progress" max="100" value="70"></progress>
```
#### Rules
- Add one color (`progress-primary`). Works on `<progress>`.
