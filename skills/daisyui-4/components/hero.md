### Hero
Hero is a component for displaying a large box or image with a title and description.

[Hero documentation](https://v4.daisyui.com/components/hero/)

#### Class names
- component: `hero`, `hero-content`, `hero-overlay`

#### Syntax
```html
<div class="hero">
  <div class="hero-content">Content</div>
</div>
```
#### Rules
- `hero-content` centers content inside the `hero` box; add `hero-overlay` over an image.
