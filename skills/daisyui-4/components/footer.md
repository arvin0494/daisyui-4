### Footer
Footer can contain logo, copyright notice, and links to other pages.

[Footer documentation](https://v4.daisyui.com/components/footer/)

#### Class names
- component: `footer`, `footer-title`
- modifier: `footer-center`

#### Syntax
```html
<footer class="footer bg-neutral text-neutral-content">
  <div><h6 class="footer-title">Brand</h6></div>
</footer>
```
#### Rules
- `footer-title` styles a header. `footer-center` enables a centered multi-column layout.
