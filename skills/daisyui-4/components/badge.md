### Badge
Badges are used to inform the user of the status of specific data.

[Badge documentation](https://v4.daisyui.com/components/badge/)

#### Class names
- component: `badge`
- color: `badge-neutral`, `badge-primary`, `badge-secondary`, `badge-accent`, `badge-ghost`, `badge-info`, `badge-success`, `badge-warning`, `badge-error`
- style: `badge-outline`
- size: `badge-lg`, `badge-md`, `badge-sm`, `badge-xs`

#### Syntax
```html
<a class="badge">Badge</a>
```
#### Rules
- Add one color modifier or `badge-outline`.
- Badges are small; keep the text short.
