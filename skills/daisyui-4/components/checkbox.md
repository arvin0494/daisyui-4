### Checkbox
Checkboxes are used to select or deselect a value.

[Checkbox documentation](https://v4.daisyui.com/components/checkbox/)

#### Class names
- component: `form-control`, `label`, `checkbox`
- color: `checkbox-primary`, `checkbox-secondary`, `checkbox-accent`, `checkbox-success`, `checkbox-warning`, `checkbox-info`, `checkbox-error`
- size: `checkbox-lg`, `checkbox-md`, `checkbox-sm`, `checkbox-xs`

#### Syntax
```html
<input type="checkbox" class="checkbox" />
```
#### Rules
- Add one color (`checkbox-primary`) and one size (`checkbox-lg`).
- Wrap with a `label` and `form-control` for labels and spacing.
