### Card
Cards are used to group and display content in a way that is easily readable.

[Card documentation](https://v4.daisyui.com/components/card/)

#### Class names
- component: `card`, `card-title`, `card-body`, `card-actions`
- modifier: `card-bordered`, `image-full`, `card-normal`, `card-compact`, `card-side`

#### Syntax
```html
<div class="card">
  <div class="card-body">Content</div>
</div>
```
#### Rules
- `card-body` wraps content and `card-title` marks the heading.
- Use `card-side` to put the image beside the content, `card-bordered` to add a border, and `image-full` for a full-bleed image.
