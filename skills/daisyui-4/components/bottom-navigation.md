### Bottom navigation
Bottom navigation bar allows navigation between primary screens.

[Bottom navigation documentation](https://v4.daisyui.com/components/bottom-navigation/)

#### Class names
- component: `btm-nav`
- behavior: `active`, `disabled`
- size: `btm-nav-xs`, `btm-nav-sm`, `btm-nav-md`, `btm-nav-lg`

#### Syntax
```html
<div class="btm-nav">
  <button>Home</button><button>Users</button><button>Settings</button>
</div>
```
#### Rules
- Use `btm-nav` as the container and `button` items inside.
- Add `active` to the selected item and `btm-nav-{size}` to change size.
