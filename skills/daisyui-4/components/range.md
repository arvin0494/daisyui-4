### Range slider
Range slider is used to select a value by sliding a handle.

[Range slider documentation](https://v4.daisyui.com/components/range/)

#### Class names
- component: `range`
- color: `range-primary`, `range-secondary`, `range-accent`, `range-success`, `range-info`, `range-warning`, `range-error`
- size: `range-lg`, `range-md`, `range-sm`, `range-xs`

#### Syntax
```html
<input type="range" class="range" min="0" max="100" />
```
#### Rules
- Add one color (`range-primary`) and one size (`range-lg`).
