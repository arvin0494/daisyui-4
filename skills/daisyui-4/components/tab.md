### Tabs
Tabs can be used to show a list of links in a tabbed format.

[Tabs documentation](https://v4.daisyui.com/components/tab/)

#### Class names
- component: `tabs`, `tab`, `tab-content`
- behavior: `tab-active`, `tab-disabled`
- size: `tabs-xs`, `tabs-sm`, `tabs-md`, `tabs-lg`
- modifier: `tabs-boxed`, `tabs-bordered`, `tabs-lifted`

#### Syntax
```html
<div class="tabs">
  <a class="tab">Tab 1</a>
  <a class="tab">Tab 2</a>
</div>
```
#### Rules
- `tabs` is the container; `tab` is each tab link.
- Use `tabs-boxed`, `tabs-bordered`, or `tabs-lifted` for a style, `tabs-{size}` for size, and `tab-active` / `tab-disabled` on tabs.
