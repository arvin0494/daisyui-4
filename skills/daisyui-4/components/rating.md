### Rating
Rating is a set of radio buttons that allow the user to rate something.

[Rating documentation](https://v4.daisyui.com/components/rating/)

#### Class names
- component: `rating`
- size: `rating-lg`, `rating-md`, `rating-sm`, `rating-xs`
- modifier: `rating-half`, `rating-hidden`

#### Syntax
```html
<div class="rating">Stars</div>
```
#### Rules
- Add `rating-half` for half-star steps and one size (`rating-lg`).
- `rating-hidden` hides the input element for JS-controlled ratings.
