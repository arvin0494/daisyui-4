### Artboard
Artboard provides a fixed-size container to display demo content on a mobile size.

[Artboard documentation](https://v4.daisyui.com/components/artboard/)

#### Class names
- component: `artboard`
- modifier: `artboard-demo`, `phone-1`, `phone-2`, `phone-3`, `phone-4`, `phone-5`, `phone-6`, `artboard-horizontal`

#### Syntax
```html
<div class="artboard phone">Content</div>
```
#### Rules
- `artboard.phone` (phone-1..phone-6) sizes the container to a phone; `artboard-horizontal` orients it horizontally.
