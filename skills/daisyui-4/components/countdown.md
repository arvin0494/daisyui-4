### Countdown
Countdown gives you a transition effect of changing numbers.

[Countdown documentation](https://v4.daisyui.com/components/countdown/)

#### Class names
- component: `countdown`

#### Syntax
```html
<span class="countdown" style="--value:2;--digits:1;">20</span>
```
#### Rules
- Set `--value` and `--digits` inline styles to control the number.
