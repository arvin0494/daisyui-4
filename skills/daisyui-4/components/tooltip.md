### Tooltip
Tooltip can be used to show a message when hovering over an element.

[Tooltip documentation](https://v4.daisyui.com/components/tooltip/)

#### Class names
- component: `tooltip-open`
- color: `tooltip-primary`, `tooltip-secondary`, `tooltip-accent`, `tooltip-info`, `tooltip-success`, `tooltip-warning`, `tooltip-error`
- modifier: `tooltip`, `tooltip-top`, `tooltip-bottom`, `tooltip-left`, `tooltip-right`

#### Syntax
```html
<button class="tooltip" data-tip="Tip text">Hover</button>
```
#### Rules
- Add `data-tip` for the tooltip text.
- Choose a position (`tooltip-top`, `tooltip-bottom`, `tooltip-left`, `tooltip-right`) and an optional color.
