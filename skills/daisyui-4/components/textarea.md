### Textarea
Textarea allows users to enter text in multiple lines.

[Textarea documentation](https://v4.daisyui.com/components/textarea/)

#### Class names
- component: `form-control`
- color: `textarea-ghost`, `textarea-primary`, `textarea-secondary`, `textarea-accent`, `textarea-info`, `textarea-success`, `textarea-warning`, `textarea-error`
- size: `textarea-lg`, `textarea-md`, `textarea-sm`, `textarea-xs`
- modifier: `label`, `textarea`, `textarea-bordered`

#### Syntax
```html
<textarea class="textarea" placeholder="Bio"></textarea>
```
#### Rules
- Wrap in `form-control` and `label` for spacing and a label.
- Add one color (`textarea-primary`) or a style (`textarea-bordered`, `textarea-ghost`), one size, and `textarea-error`.
