### Stat
Stat is used to show numbers and data in a box.

[Stat documentation](https://v4.daisyui.com/components/stat/)

#### Class names
- component: `stats`, `stat`, `stat-title`, `stat-value`, `stat-desc`, `stat-figure`, `stat-actions`
- modifier: `stats-horizontal`, `stats-vertical`

#### Syntax
```html
<div class="stats">
  <div class="stat"><div class="stat-value">42</div></div>
</div>
```
#### Rules
- Use `stats` as the container and `stat` for each block with `stat-value`, `stat-title`, `stat-desc`, `stat-figure`, `stat-actions`.
- Use `stats-horizontal` / `stats-vertical` for orientation.
