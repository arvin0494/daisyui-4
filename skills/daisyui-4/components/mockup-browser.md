### Browser mockup
Browser mockup shows a box that looks like a browser window.

[Browser mockup documentation](https://v4.daisyui.com/components/mockup-browser/)

#### Class names
- component: `mockup-browser`, `mockup-browser-toolbar`

#### Syntax
```html
<div class="mockup-browser">
  <div class="mockup-browser-toolbar">URL</div>
  <div>Content</div>
</div>
```
#### Rules
- `mockup-browser-toolbar` adds the browser toolbar.
