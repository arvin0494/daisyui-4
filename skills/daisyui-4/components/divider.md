### Divider
Divider will be used to separate content vertically or horizontally.

[Divider documentation](https://v4.daisyui.com/components/divider/)

#### Class names
- component: `divider`
- color: `divider-neutral`, `divider-primary`, `divider-secondary`, `divider-accent`, `divider-success`, `divider-warning`, `divider-info`, `divider-error`
- modifier: `divider-vertical`, `divider-horizontal`, `divider-start`, `divider-end`

#### Syntax
```html
<div class="divider">Divider</div>
```
#### Rules
- Add one color modifier or `divider-vertical` / `divider-horizontal` for orientation.
