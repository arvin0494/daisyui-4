### Link
Link adds the missing underline style to links.

[Link documentation](https://v4.daisyui.com/components/link/)

#### Class names
- component: `link`
- color: `link-neutral`, `link-primary`, `link-secondary`, `link-accent`, `link-success`, `link-info`, `link-warning`, `link-error`
- behavior: `link-hover`

#### Syntax
```html
<a class="link">Link</a>
```
#### Rules
- Add one color (`link-primary`).
- `link-hover` changes the style on hover.
