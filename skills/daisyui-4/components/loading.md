### Loading
Loading shows an animation to indicate that something is loading.

[Loading documentation](https://v4.daisyui.com/components/loading/)

#### Class names
- component: `loading`
- modifier: `loading-spinner`, `loading-dots`, `loading-ring`, `loading-ball`, `loading-bars`, `loading-infinity`

#### Syntax
```html
<span class="loading loading-spinner"></span>
```
#### Rules
- Choose a spinner type: `loading-spinner`, `loading-dots`, `loading-ring`, `loading-ball`, `loading-bars`, `loading-infinity`.
