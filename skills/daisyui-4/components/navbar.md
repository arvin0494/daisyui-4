### Navbar
Navbar is used to show a navigation bar on the top of the page.

[Navbar documentation](https://v4.daisyui.com/components/navbar/)

#### Class names
- component: `navbar`, `navbar-start`, `navbar-center`, `navbar-end`

#### Syntax
```html
<div class="navbar">
  <div class="navbar-start">Left</div>
  <div class="navbar-center">Center</div>
  <div class="navbar-end">Right</div>
</div>
```
#### Rules
- `navbar-start`, `navbar-center`, `navbar-end` distribute content.
- Add `sticky`, `bg`, and `backdrop-blur` Tailwind utilities for a fixed navbar.
