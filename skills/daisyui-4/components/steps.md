### Steps
Steps can be used to show a list of steps in a process.

[Steps documentation](https://v4.daisyui.com/components/steps/)

#### Class names
- component: `steps`, `step`
- color: `step-primary`, `step-secondary`, `step-accent`, `step-info`, `step-success`, `step-warning`, `step-error`
- modifier: `steps-vertical`, `steps-horizontal`

#### Syntax
```html
<ul class="steps">
  <li class="step">Step 1</li>
  <li class="step step-primary">Step 2</li>
</ul>
```
#### Rules
- `step` is each step; add a color (`step-primary`). Use `steps-vertical` / `steps-horizontal` for orientation.
