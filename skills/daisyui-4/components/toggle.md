### Toggle
Toggle is a checkbox that is styled to look like a switch button.

[Toggle documentation](https://v4.daisyui.com/components/toggle/)

#### Class names
- component: `form-control`, `toggle`
- color: `toggle-primary`, `toggle-secondary`, `toggle-accent`, `toggle-success`, `toggle-warning`, `toggle-info`, `toggle-error`
- size: `toggle-lg`, `toggle-md`, `toggle-sm`, `toggle-xs`

#### Syntax
```html
<input type="toggle" class="toggle" />
```
#### Rules
- Add one color (`toggle-primary`) and one size (`toggle-lg`).
- Wrap with a `label` and `form-control` for labels and spacing.
