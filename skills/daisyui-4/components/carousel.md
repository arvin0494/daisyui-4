### Carousel
Carousel show images or content in a scrollable area.

[Carousel documentation](https://v4.daisyui.com/components/carousel/)

#### Class names
- component: `carousel`, `carousel-item`
- modifier: `carousel-start`, `carousel-center`, `carousel-end`, `carousel-vertical`

#### Syntax
```html
<div class="carousel">
  <div class="carousel-item">A</div>
  <div class="carousel-item">B</div>
</div>
```
#### Rules
- `carousel-item` is one slide; add `carousel-vertical` for a vertical slider.
