### Stack
Stack visually puts elements on top of each other.

[Stack documentation](https://v4.daisyui.com/components/stack/)

#### Class names
- component: `stack`

#### Syntax
```html
<div class="stack">
  <div>1</div><div>2</div><div>3</div>
</div>
```
#### Rules
- Stack children with `stack`; add `sm` / `md` / `lg` Tailwind utilities to control the offset.
