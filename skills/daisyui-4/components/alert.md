### Alert
Alert informs users about important events.

[Alert documentation](https://v4.daisyui.com/components/alert/)

#### Class names
- component: `alert`
- color: `alert-info`, `alert-success`, `alert-warning`, `alert-error`

#### Syntax
```html
<div class="alert">
  <span>New message arrived</span>
</div>
```
#### Rules
- Add one color modifier (`alert-info`, `alert-success`, `alert-warning`, `alert-error`).
- Put the message content directly inside the `alert`.
