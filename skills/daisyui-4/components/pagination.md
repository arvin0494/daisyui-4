### Pagination
Pagination is a group of buttons that allow the user to navigate between a set of related content.

[Pagination documentation](https://v4.daisyui.com/components/pagination/)

#### Class names
- component: `join`

#### Syntax
```html
<div class="join">
  <button class="join-item btn">1</button>
  <button class="join-item btn btn-active">2</button>
</div>
```
#### Rules
- Reuse the `join` component: `join` + `join-item` children.
- Add `btn-active` to the current page button.
