### Menu
Menu is used to display a list of links vertically or horizontally.

[Menu documentation](https://v4.daisyui.com/components/menu/)

#### Class names
- component: `menu`, `menu-title`, `menu-dropdown-toggle`, `menu-dropdown`
- behavior: `disabled`, `active`, `menu-dropdown-show`
- size: `menu-xs`, `menu-sm`, `menu-md`, `menu-lg`
- modifier: `focus`, `menu-vertical`, `menu-horizontal`

#### Syntax
```html
<ul class="menu">
  <li><a>Item 1</a></li>
</ul>
```
#### Rules
- `menu` is a `<ul>` of `<li><a>` items.
- Add `menu-title`, one size (`menu-lg`), orientation (`menu-vertical` / `menu-horizontal`), and `active` / `disabled` on items.
