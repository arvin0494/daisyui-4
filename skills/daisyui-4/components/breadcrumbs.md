### Breadcrumbs
Breadcrumbs helps users to navigate through the website.

[Breadcrumbs documentation](https://v4.daisyui.com/components/breadcrumbs/)

#### Class names
- component: `breadcrumbs`

#### Syntax
```html
<div class="breadcrumbs text-sm">
  <ul><li><a>Home</a></li><li>Folder</li></ul>
</div>
```
#### Rules
- Wrap links in a `ul` inside `breadcrumbs`. The last item is the current page (no link).
