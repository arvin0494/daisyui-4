### Mask
Mask crops the content of the element to common shapes.

[Mask documentation](https://v4.daisyui.com/components/mask/)

#### Class names
- component: `mask`
- modifier: `mask-squircle`, `mask-heart`, `mask-hexagon`, `mask-hexagon-2`, `mask-decagon`, `mask-pentagon`, `mask-diamond`, `mask-square`, `mask-circle`, `mask-parallelogram`, `mask-parallelogram-2`, `mask-parallelogram-3`, `mask-parallelogram-4`, `mask-star`, `mask-star-2`, `mask-triangle`, `mask-triangle-2`, `mask-triangle-3`, `mask-triangle-4`, `mask-half-1`, `mask-half-2`

#### Syntax
```html
<div class="mask mask-squircle">Image</div>
```
#### Rules
- Add a shape modifier (`mask-circle`, `mask-square`, `mask-heart`, `mask-hexagon`, `mask-star`, ...).
